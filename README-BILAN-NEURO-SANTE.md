# Bilan Neuro-Santé

Prototype autonome en HTML/CSS/JavaScript. Page d'accueil : `index.html`.

## Publication GitHub Pages
1. Ouvrir **Settings → Pages** dans le dépôt.
2. Sous **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche `logiciel-bilan-neuro-sante` et le dossier `/ (root)`, puis enregistrer.
4. Attendre la publication indiquée par GitHub. URL attendue : https://sophiecurutchet.github.io/test-9/

## Limites importantes
Ce prototype est un outil de démonstration, pas un dispositif médical validé. Les 26 items sont exploratoires et les quatre indices composites ne sont pas validés. Ils ne doivent pas servir au diagnostic, au triage automatisé ou à la décision thérapeutique. Les questionnaires validés (PHQ-4, PSS-4, PEG, PROMIS, etc.) doivent être intégrés uniquement dans leur version française autorisée, avec leurs règles de cotation et licences respectées.

Aucune donnée n'est transmise à un serveur dans cette version. L'historique est uniquement en mémoire de session et les images sont seulement prévisualisées localement. **Ne saisir aucune donnée de santé identifiable ni photographie de patient sur ce site public.** GitHub Pages est un hébergement statique public, sans authentification patient ni garanties d'hébergement de données de santé adaptées. Avant un usage réel : analyse RGPD, consentement et information, contrôle d'accès, chiffrement, sauvegarde, durées de conservation, procédure d'effacement et hébergeur conforme aux exigences françaises applicables (dont HDS lorsque requis), avec validation juridique/DPO.

Les projections à 5–20 ans et les effets préventifs ou thérapeutiques ne sont pas calculés : aucune extrapolation clinique n'est faite.
